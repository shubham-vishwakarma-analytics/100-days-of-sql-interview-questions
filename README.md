# 🗓️ 100 Days of SQL — Interview Questions Challenge

Solving **one SQL interview question every day for 100 days**, focusing on interview-style problems and business scenarios for Data Analyst and related roles.

| | |
|---|---|
| 📅 **Start Date** | 17 October 2026 |
| 🏁 **End Date** | 24 January 2027 |
| 📌 **Practice Sources** | [NextLeap](https://nextleap.app/), [LeetCode](https://leetcode.com/problemset/database/), [HackerRank](https://www.hackerrank.com/domains/sql), [StrataScratch](https://www.stratascratch.com/) |
| 🧰 **Preferred SQL Dialect** | Microsoft SQL Server (T-SQL), where supported |
| 📸 **Proof** | SQL solution file and screenshot of successful execution / accepted submission |

> **Dialect note:** Some platforms use MySQL, PostgreSQL, or another SQL dialect. Use SQL Server syntax where possible and note platform-specific differences when necessary.

## 🎯 Challenge Goals

- Practise SQL consistently every day for 100 days.
- Prepare for Data Analyst, Business Analyst, and SQL-focused interviews.
- Strengthen joins, aggregations, subqueries, window functions, and business-case problem solving.
- Maintain a public record of progress with SQL files and screenshots.

```text

└── resources/

```

Each daily folder should contain:
- `solution.sql` — your query, with brief comments if helpful.
- `screenshot.png` — proof of accepted submission or successful query execution.
